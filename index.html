01

Install Python & Pip

Python is the programming language we'll write the bot in. Pip is its built-in tool for installing extra code libraries. Let's get both set up correctly — this is the step most beginners get stuck on, so we'll go slowly.

What are Python and Pip, really?

Think of Python as the language your computer needs to understand to run the instructions we're about to write. Pip is a helper tool that ships with Python — its only job is to download and install extra pieces of code (called "libraries" or "packages") that other people have already written, so you don't have to build everything from scratch.

Download the installer

  1. Go to python.org/downloads in your browser.
  2. Click the big yellow "Download Python 3.x" button — it automatically detects your operating system.
  3. Open the downloaded file once it finishes downloading.
The most important checkbox in this whole tutorial

On the very first installer screen (Windows), tick "Add python.exe to PATH" before clicking Install. This tells your computer where to find Python when you type commands. Skip this, and nothing in Step 2 onward will work.

Installer screen: a checkbox labelled "Add python.exe to PATH" sits at the bottom — check it, then click "Install Now".

Open a terminal to verify it worked

A "terminal" (or "command line") is a text-only window where you type instructions directly to your computer instead of clicking icons. Choose the path that matches your setup:

Open VS Code, then go to the top menu Terminal → New Terminal. A panel opens at the bottom of the window — that's your terminal, built right into the editor.

On Windows, press the Start key, type cmd, and press Enter. On macOS, open Spotlight (Cmd + Space), type Terminal, and press Enter. We'll use Notepad (or TextEdit) later to write the actual code.

Now type this into the terminal and press Enter:

terminal 
python --version
pip --version

If both commands print a version number (e.g. Python 3.12.4), you're done — Python is installed correctly. If you see "not recognized as an internal or external command," open the accordion below.

Troubleshooting

Python wasn't added to PATH during install. Uninstall Python from "Add or remove programs," reinstall it, and make sure to tick "Add python.exe to PATH" on the first screen before clicking Install.
macOS ships an old system Python. After installing from python.org, use python3 and pip3 instead of python and pip throughout this guide.
02

Install the discord.py library

Python itself doesn't know anything about Discord. We need a "library" — pre-written code that handles all the complicated communication with Discord's servers for us. That library is called discord.py.

Create a project folder first

Make a new folder anywhere you'll remember — for example Desktop/my-discord-bot. Everything we create in this tutorial (the code file, the token file) will live inside it.

In VS Code, go to File → Open Folder and select (or create) your my-discord-bot folder. Then open the built-in terminal with Terminal → New Terminal — it automatically opens inside that folder.

In your terminal, "move into" the folder using the cd (change directory) command, for example:

terminal
cd Desktop/my-discord-bot

Install discord.py with pip

With your terminal open inside the project folder, run:

terminal
pip install discord.py

We'll also need one more tiny library later for keeping our bot's secret token safe — install it now while we're here:

terminal
pip install python-dotenv
What just happened?

Pip reached out to the Python Package Index (a public library of free code), downloaded discord.py and python-dotenv, and installed them so any Python file in this folder can now use them with a simple import line.

Double-check the install

terminal
pip show discord.py

You should see a block of text with a Name, Version, and Location. That confirms the library is installed and ready to use.

Not for this tutorial. A virtual environment keeps each project's libraries separate, which is great practice later on, but it adds an extra concept while you're still learning the basics. Feel free to skip it for now.
03

Create the bot & get your token

Before your code can control a bot, Discord needs to know that bot exists. We'll create it on the Discord Developer Portal and collect a secret "token" — think of it as the bot's password.

Create the application

  1. Go to discord.com/developers/applications and log in with your Discord account.
  2. Click "New Application" in the top-right corner.
  3. Give it a name (this becomes your bot's display name) and accept the terms, then click Create.

Turn it into a bot & grab the token

  1. In the left sidebar, click "Bot."
  2. Click "Reset Token" (or "Copy," if you're seeing it for the first time) and confirm.
  3. Click "Copy" to copy your token to the clipboard. This is shown to you only once — save it somewhere safe immediately.
Your token is a password — treat it like one

Anyone with your token can fully control your bot. Never paste it into chat, a screenshot, or a public GitHub repository. If you ever expose it by accident, come back to this page and click "Reset Token" immediately to invalidate the old one.

Turn on Message Content Intent

Still on the "Bot" page, scroll down to "Privileged Gateway Intents" and switch on "Message Content Intent." This gives your bot permission to actually read the text inside messages — without it, commands like the ones we'll write in Step 4 won't work.

Bot page: a toggle switch labelled "Message Content Intent" under Privileged Gateway Intents — flip it on and click "Save Changes."

Store the token safely in a .env file

Instead of typing your token directly into your code (where it could accidentally get shared), we'll keep it in a separate file named exactly .env, inside your project folder.

In the Explorer panel on the left, click the "New File" icon and name it exactly .env (yes, starting with a dot, no other extension). Open it and add the line below.

Open Notepad, add the line below, then choose File → Save As. Navigate to your project folder, change "Save as type" to All Files, and set the filename to exactly .env — otherwise Notepad will secretly save it as .env.txt, which won't work.

.env
DISCORD_TOKEN=paste-your-token-here

Replace paste-your-token-here with the real token you copied — no quotes, no spaces around the = sign.

If you ever upload this project to GitHub

Create a file named .gitignore in the same folder and add a single line: .env. That tells GitHub to never upload your secret file publicly.

04

Write the code, line by line

Now for the fun part. We'll create one file, bot.py, and build it up piece by piece — explaining exactly what every line does before you ever have to run it.

Create bot.py

Click the "New File" icon in the Explorer panel, name it bot.py, and it opens ready to edit — with color-coded syntax highlighting built in.

Open Notepad, and when you save, use File → Save As, set "Save as type" to All Files, and name it exactly bot.py in your project folder.

Type (or copy) this complete code into bot.py:

bot.py 
# bot.py

import os
import discord
from discord.ext import commands
from dotenv import load_dotenv

# Load the variables from our .env file into this program
load_dotenv()
TOKEN = os.getenv("DISCORD_TOKEN")

# Tell Discord which events our bot is allowed to see
intents = discord.Intents.default()
intents.message_content = True

# Create the bot itself, with "!" as its command prefix
bot = commands.Bot(command_prefix="!", intents=intents)

@bot.event
async def on_ready():
    print(f"✅ Logged in as {bot.user} (ID: {bot.user.id})")
    print("------")

@bot.command()
async def hello(ctx):
    """Replies with a friendly greeting."""
    await ctx.send(f"Hey {ctx.author.mention}! 👋 I'm alive and ready to go.")

@bot.command()
async def ping(ctx):
    """Shows the bot's latency in milliseconds."""
    latency = round(bot.latency * 1000)
    await ctx.send(f"🏓 Pong! Latency: {latency}ms")

bot.run(TOKEN)

What every part of this actually does

  • import os / discord / commands / dotenv — these lines pull in the libraries we installed in Step 2, plus Python's built-in os module for reading environment variables.
  • load_dotenv() and os.getenv(...) — these open your .env file and read the DISCORD_TOKEN value into the variable TOKEN, so your real token never appears in the code itself.
  • intents — "intents" are permissions that tell Discord which categories of events your bot is allowed to receive. message_content = True matches the toggle you switched on in Step 3.
  • commands.Bot(command_prefix="!", ...) — this creates the bot object and decides that every command must start with ! in chat, e.g. !hello.
  • async def and await — Discord bots constantly wait on network activity (messages arriving, replies sending). async/await lets Python handle many of these waiting tasks at once instead of freezing up.
  • @bot.event above on_ready() — this decorator tells discord.py "run this function automatically the moment the bot successfully connects." It's perfect for a startup confirmation message.
  • @bot.command() — this decorator turns any function directly below it into a chat command. The function name becomes the command name, so def hello(ctx): becomes !hello.
  • ctx ("context") — automatically holds information about where the command was used: which channel, which user, which server — so ctx.send(...) knows exactly where to reply.
  • bot.run(TOKEN) — the final line, always last in the file. It logs the bot into Discord using your token and keeps the program running, listening for events, until you stop it.
Indentation matters in Python

Notice how the lines inside each function are indented with 4 spaces. Python uses that indentation (not curly braces) to know which lines belong "inside" a function. Keep it consistent, or you'll get an IndentationError.

05

Run the bot & invite it to your server

This is the moment it all comes together — start the script, watch it come online, and bring it into a real Discord server to try your commands.

Run bot.py

With bot.py open, click the ▶ "Run" button in the top-right corner, or open the integrated terminal and type the command below.

In your terminal, make sure you're still inside the project folder (use cd if needed), then run the command below.

terminal
python bot.py

Success looks like a line printed in your terminal: ✅ Logged in as YourBotName (ID: ...). Leave this window open — closing it stops the bot.

Generate an invite link

  1. Back on the Developer Portal, open your application and click "OAuth2" in the sidebar, then "URL Generator."
  2. Under Scopes, check "bot."
  3. Under Bot Permissions, check at least "Send Messages" and "Read Message History."
  4. Scroll down, copy the generated URL at the bottom, and open it in a new browser tab.
  5. Choose a server you manage from the dropdown and click "Authorize."

Test your commands

In any text channel your bot can see, type !hello and press Enter — your bot should reply within a second. Try !ping too. That's it: you just wrote and ran a real Discord bot.

Troubleshooting

Pip installed the library into a different Python than the one running your script. Try python -m pip install discord.py instead, which forces the install into the exact Python you're using.
Your .env file's token is missing, mistyped, or was reset on the portal. Go back to the "Bot" page, click "Reset Token," copy the new one, and paste it into your .env file again.
You enabled intents.message_content in code but forgot to flip on "Message Content Intent" in the Developer Portal. Go back to Step 3 and turn it on.
Your script isn't currently running. Check the terminal window for an error message that stopped it, fix the issue, and run python bot.py again. The bot stays online only while the script is running.
Nice work — what's next?

Right now your bot only runs while your computer is on and the script is open. To keep it online 24/7, you'll eventually want to host it somewhere like a small VPS or a service such as Railway — check the Resources section below for where to learn more.
